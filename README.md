# Emergency Readiness Calculator

A GitHub Copilot-ready VS Code starter for a static-data prototype of the offshore preparedness use case discussed in the technical Spotfire session.

## Run
```bash
npm install
npm run dev
npm run test
```

## Use with GitHub Copilot
1. Open this folder in VS Code.
2. Ensure GitHub Copilot and GitHub Copilot Chat are enabled.
3. Copilot automatically reads `.github/copilot-instructions.md`.
4. Open `docs/BUILD-PROMPTS.md` and use the prompts in order.

## Prototype scope
- Static CSV and JSON only
- Activity map, filtering, SAR/DFU2 ranking, DFU7 medevac combinations, and ERRV/DFU5 ranking
- Resource-specific capacities and mobilization times
- Replaceable domain calculations with tests

## Important
All records, coordinates, parameters, names and calculations are synthetic or illustrative. Do not use this prototype for navigation, emergency response, regulatory assessment, commercial calculation or operational decision-making. Exact formulas must be validated with business owners before production use.
